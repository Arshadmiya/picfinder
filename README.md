📸 PicFinder – Image Search Web App

A fully responsive Image Search Application built using the Unsplash API. Users can search for any type of image and browse high-quality results instantly. The app also includes an Instagram-style like feature, allowing users to interact with images by liking/unliking them seamlessly.

🔗 Live Demo

👉 https://arshadmiya.github.io/picfinder/

✨ Features
🔍 Image Search

Search for any keyword (e.g., nature, cars, animals, wallpapers, etc.)

Uses Unsplash API to fetch real-time high-quality images.

❤️ Instagram-like “Like” Feature

Double click on the image to like an image.

🚀 How It Works

User enters a search term in the input field.

JavaScript sends a request to the Unsplash API using fetch().

Response images are displayed in a responsive gallery layout.

Users can:

View images

Like images

Load more results (if implemented)
